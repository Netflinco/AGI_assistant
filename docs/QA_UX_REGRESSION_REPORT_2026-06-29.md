# 万象巡检助理交互优化回归报告

## 结论

本轮交互优化通过功能烟测和浏览器关键链路回归，可作为当前本地 Demo 的默认交互版本。

## 优化目标

- 将首屏从“系统能力展示”改为“用户任务入口”。
- 降低 Plan、Tool、Trace 等内部概念对普通用户的认知负担。
- 参考 AI Coding 产品的交互方式，用单一输入框承接主要操作。
- 查询直接返回结果，修改配置必须先展示影响范围并由用户确认。
- 任务轨迹、证据和技术细节按需展开。

## 已完成改动

1. 重构为“轻量侧栏 + 单一工作区 + 按需详情抽屉”。
2. 增加创建任务、查询告警、分析数据、检查设备四个首屏快捷入口。
3. 输入框固定在对话底部，支持 Enter 发送和 Shift + Enter 换行。
4. 将配置确认卡嵌入对话，突出范围、能力、时间、离线设备警告和确认按钮。
5. 将执行进度和告警证据收进任务详情抽屉。
6. 将接口错误转换为面向用户的中文提示。
7. 组织或角色切换时清空旧对话、计划和证据状态。
8. 默认告警列表按当前组织及下级组织过滤；自然语言查询结果保留查询条件返回范围。
9. 增加键盘焦点、ARIA 标签、空状态和处理中状态。
10. 根据角色调整首屏任务：无配置权限的角色改为“查看待处理告警”，并隐藏不可访问的操作记录入口。
11. 快捷任务随当前组织动态变化，避免切换组织后仍查询旧门店。
12. 支持缺失信息的多轮续接，例如先创建任务、再单独补充“每天 9 点到 22 点”。
13. 手机宽度使用底部导航，并保留新建对话、当前范围和任务详情入口。

## 回归中修复

- 修复隐藏待确认状态仍占位的问题。

## 研发整改复核

- 已将缺失信息续接从前端字符串拼接下沉到后端会话服务，网页和 API 调用均可完成多轮补槽。
- 已增加“先创建任务、再单独补充每天 9 点到 22 点”的自动化回归断言。
- 已修复固定日期基准，`昨天`、`上周`、`下周`按当前上海时区日期解析，Demo 事件数据随日期滚动。
- `python3 smoke_test.py`、Python 语法检查、前端 JavaScript 语法检查和 HTML ID 唯一性检查均通过。
