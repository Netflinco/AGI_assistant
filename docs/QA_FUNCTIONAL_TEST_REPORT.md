## 4. 关键验证记录

| 验证点 | 结果 |
|---|---|
| 写操作必须计划卡确认 | 订阅 Plan 生成后，订阅数量未变化 |
| 幂等键生效 | 第二次 confirm 返回 `deduped=true` |
| 后端权限不是 UI 假限制 | 直接调用 API 也返回 403 |
| 事件证据可信 | 查询结果每条事件均绑定 evidence |
| 统计不编造 | 统计结果来自事件聚合，并返回口径 |
| 误报闭环 | 反馈后事件状态变为 `FALSE_POSITIVE`，返回 `badcase_id` |
| 审计追踪 | `subscription.create`、`analytics.query`、`event.feedback.create` 均可查 |

## 5. 剩余风险

| 风险 | 说明 | 建议 |
|---|---|---|
| 意图识别为规则实现 | 当前覆盖 P0 高频话术，不等同真实客户泛化能力 | P1 接入 LLM 结构化抽取和 200+ 评测集 |
| SQLite 单机存储 | 适合 MVP，不适合生产并发和大事件量 | 生产迁移 PostgreSQL/MySQL |
| 证据为动态 SVG | 当前用于流程验证，不是真实视频证据 | 接入对象存储、签名 URL、视频片段 |
| 即时巡检未实现 | PRD 标注为 P1 | P1 接入任务队列和模型网关 |
| 嵌入 SDK 未实现 | 当前仅独立入口 | P1 实现 Side Panel 和 context token |

## 6. 发布建议

建议作为 P0 技术验证 Demo 发布，可用于内部产品、研发、交付评审；不建议直接面向真实客户生产使用。进入试点前应完成真实 RBAC、真实组织摄像头 API、真实事件证据存储和 LLM 评测集接入。
