# DeepVision 跨夜鉴权与对话初始化回归报告

## 回归结论

问题已修复，服务已重启并通过真实 OPPO 在线数据回归。截图中的查询可自动识别为告警查询并返回 6 条在线结果，不再出现 `conversation_id` 空引用。

## 根因与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 跨夜后在线接口持续 502 | 本地缓存 Token 仍处于 TTL 内，但上游已返回 HTTP 401；连接器只处理业务响应中的鉴权码 | HTTP 401 与业务鉴权失效统一清除 Token、重新登录并重试一次 |
| 页面显示原始 JavaScript 错误 | 初始化失败后页面仍可发送，`state.conversation` 为 `null` | 增加初始化状态与空会话保护，未连接时禁用输入和快捷入口 |
| 失败后无法自助恢复 | 顶部刷新仅重载部分数据 | 初始化失败时显示“重新连接”，恢复 Bootstrap、会话、能力和审计数据 |
