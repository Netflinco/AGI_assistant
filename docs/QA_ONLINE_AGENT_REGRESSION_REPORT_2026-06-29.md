# OPPO 在线 Agent 联调与回归报告

## 结论

OPPO 在线只读 Agent 已完成真实数据联调、自动化合约测试和桌面/移动端浏览器回归，可进入只读功能验收；巡检任务创建、配置修改和告警反馈仍不具备发布条件。

## 交付范围

- DeepVision PaaS 客户端认证、Token 缓存和错误净化。
- OPPO 组织、摄像头、已配置能力、告警列表、详情和证据查询。
- 告警类型/时间/门店筛选和全租户门店排行。
- OpenAI-compatible 模型意图适配器与显式本地降级。
- 在线只读状态、工具轨迹、真实证据和写操作阻断 UI。

## 已修复缺陷

1. “查看已经配置了哪些能力”被“配置”误判为写操作：已调整查询意图优先级并补测试。
2. “所有门店”仍沿用当前单店上下文：已解析为租户根节点并补测试。
3. 上游未返回置信度时页面显示 0%：改为“上游未提供”。
4. 在线统计把不可用的处理数和误报率显示为 0：改为“暂未提供”。
5. 移动端顶部标题被在线状态挤压换行：删除重复标题并复核无溢出。
6. 在线只读页面仍出现误报反馈按钮和创建入口：已隐藏并在后端返回 409。

## 剩余风险

1. 当前没有 LLM 网关凭证，实际运行使用明确标识的本地降级解析；模型意图准确率尚未评测。
2. 旧版 LLM 任务接口线上返回 404，写操作必须等待现行接口契约。
3. 当前用户身份仍为本地会话模拟，生产前需接 SSO/RBAC。
4. 告警统计通过门店逐个聚合，门店规模扩大后需要并发限制、缓存或专用聚合接口。
5. PaaS 证据 URL 为短时链接，长会话需要增加自动刷新策略。

## 发布建议

建议发布为“OPPO 在线只读验收版”。不得对外宣称已支持线上任务创建、订阅修改、告警反馈或真实模型意图识别。
