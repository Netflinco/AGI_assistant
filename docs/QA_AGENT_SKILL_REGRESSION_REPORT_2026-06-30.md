## 外部阻塞

1. 线上订阅创建/修改/查询执行回执：旧文档列表接口线上 404，当前资料没有创建契约。
2. 边缘服务器健康：缺少服务器列表、心跳、资源水位和在线状态接口。
3. 历史时刻抽帧：当前环境无 FFmpeg，PaaS 只有录像流接口，没有直接历史帧接口。
4. 媒体停止：按现有文档调用停止接口，线上返回厂商码 `4`；系统只标记本地释放并等待临时地址到期，不声称上游已停止。
