## 覆盖项

1. “每天 11 点巡检”创建后，首个 `next_run_at` 为首个 11:00，而不是创建时刻；“现在先巡检一遍，并每天 11 点巡检”可显式开启即时首轮。
2. 运行记录以 `scheduled_at`、`started_at`、首张 `captured_at` 计算偏差，并返回 `ON_TIME/DELAYED/PENDING`。
3. 知识库 SKU 统一大写校验；非法字符拒绝入库；检索、参考图和模型提示均携带 SKU。
4. 模型返回 SKU 必须同时命中参考图白名单和已归档镜头；无效镜头或非白名单 SKU 不持久化。
5. 结果图片、巡检历史、详情和大图预览使用右上角 UI 覆盖标签；归档原图字节与 SHA-256 不变。
6. 受控 SKU 比对按单个镜头判定：命中任意一个库内 SKU 的镜头为非风险，只展示该 SKU 标签；存在可识别出样且没有任何库内 SKU 命中的镜头才标记为风险。
7. 空画面、无可比对出样或证据不足的镜头不被当作 SKU 未命中风险；混合场景中仅未命中镜头进入红框与风险证据集合。
