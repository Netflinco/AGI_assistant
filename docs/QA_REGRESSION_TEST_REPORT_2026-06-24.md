## 4. 页面回归摘要

本次自动化主要覆盖 API 业务断言。页面已实现以下手工可回归点：

1. `/` 可进入独立 AI 巡检助理工作台。
2. 顶部可切换角色和组织。
3. 对话区可发送快捷指令。
4. 计划卡展示风险、影响范围、幂等键、警告和确认按钮。
5. 结果中心展示事件列表，事件可打开证据。
6. 统计分析展示指标、排行和口径。
7. 应用订阅列表展示由对话创建的订阅。
8. 审计日志页按权限展示。

## 5. 测试数据与副作用

自动化脚本使用临时目录中的 SQLite 数据库，测试结束后删除临时库，不污染工作区默认数据。运行真实服务时，默认数据库位于 `data/agi_inspection.db`，确认订阅和反馈会写入该库。
