状态：待用户验收

## 本次交付

- 知识库图片由“整条知识一个 SKU”升级为“每张样板图一个 SKU、特征说明、拍摄视角”。
- 新增 `asset_metadata_json` 兼容性迁移；历史知识无须重录，仍按原有默认 SKU 生成参考图元数据。
- 知识库检索、计划固化、巡检参考图、视觉模型提示及 SKU 标签白名单均使用单图元数据。
- 视觉模型只能返回当前已召回参考图中的 SKU；与单图 SKU 不一致、或不能清晰确认时会被过滤，不生成标签。
- 知识库页面支持本地多图逐张填写 SKU/视角/特征说明，编辑时可修改已保留图片；图片地址导入同样支持该字段组。

## 数据及接口约定

`POST /api/agent/knowledge` 与 `PATCH /api/agent/knowledge/{knowledge_id}` 支持：

```json
{
  "sku": "OPTIONAL-DEFAULT",
  "asset_metadata": [
    {
      "upload_index": 0,
      "sku": "KUKA-2187",
      "view_tag": "正面",
      "description": "浅色双人沙发，带左扶手"
    },
    {
      "asset_url": "/static/uploads/knowledge/.../sample.png",
      "sku": "KUKA-2188",
      "view_tag": "左侧",
      "description": "同系列左侧展示图"
    }
  ]
}
```

- `upload_index` 必须对应本次 `asset_uploads` 中的图片下标；更新已有图片时使用 `asset_url`。
- 单图 SKU 按既有 SKU 格式校验，说明最大 800 字，视角最大 80 字。
- 每条元数据必须对应本次保存的保留图片或新增图片；不能借此修改其他知识的图片。
- `reference_assets` 为知识库读取接口的标准返回字段；`asset_urls`、顶层 `sku` 继续保留以兼容已有调用方。

## 功能走查清单

1. 打开“Agent 能力 → 知识库”，新增或编辑图片型知识。
2. 选择多张本地样板图；在每张图下填写 `SKU / 视角 / 特征说明`。
3. 保存后再次编辑，确认每张保留图的三项字段可见、可改、可删除。
4. 创建引用该知识的巡检。只有现场与某张参考图清晰一致时，结果图右上角才可出现该图对应 SKU。
5. 未配置实际 OVD/VLM 或图像不可辨识时，预期输出为证据不足/系统失败，不得把猜测 SKU 写入结果图。
