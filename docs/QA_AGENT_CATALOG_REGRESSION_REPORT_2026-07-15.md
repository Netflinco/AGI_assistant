# Agent 能力中心回归测试报告

日期：2026-07-15

## 测试范围

- Agent Core 标准目录：意图、Skill、工具、路由契约。
- Manifest 校验：Skill/Tool 模板、风险级别、原始密钥阻断。
- Manifest 导入：租户隔离、版本替换、目录可见、审计记录。
- 前端能力中心：导航入口、Skill库、工具箱、意图图谱、长期记忆、知识库、Manifest 导入。
- P1 显式入口：新增 Skill、新增工具、模板填充、校验和导入。
- P2 基础闭环：长期记忆创建/查看/审计，多模态知识创建/查看/审计。
- 现有功能回归：对话、计划确认、分组巡检历史、权限、证据、数据分析、反馈、审计、凭证脱敏。

## 测试命令

```bash
python3 smoke_test.py
```

## 测试结论

通过。

已验证能力中心新增功能不影响现有巡检助手主流程。导入的第三方 Skill/工具当前为 `registry_only`，只进入目录展示、校验、审计和评估链路，不会绕过现有安全执行路径。

## 关键验收点

- `GET /api/agent/catalog` 返回内置目录、导入扩展、模板和评估指标。
- 非管理员访问能力目录返回 `403`。
- Skill Manifest 校验通过后可导入，并在目录扩展中可见。
- 包含原始 `api_key` 的 Tool Manifest 被拒绝，返回 `AGENT_MANIFEST_INVALID`。
- 前端存在 `Agent 能力` 入口、`新增 Skill`、`新增工具`、Manifest 编辑、校验、导入控件。
- 前端存在 `长期记忆` 和 `知识库` tab，可创建并查看当前租户的 P2 数据。
- `POST /api/agent/memories` 可创建业务判断口径记忆，非管理员返回 `403`。
- `POST /api/agent/knowledge` 可创建品牌规范类知识，并在能力目录统计中体现。
- 原有业务 smoke 测试全部通过。

## 残余风险

- 第三方 Skill/工具尚未绑定真实运行器，当前为安全的目录注册模式。
- YAML Manifest 暂未启用，当前前端导入格式为 JSON。
- 长期记忆和多模态知识库当前完成登记、查看、审计和目录上下文；尚未接入向量检索和执行链路自动引用。
