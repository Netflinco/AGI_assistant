## 12. Agent Skill 与 Pipeline

| 编号 | 功能点 | 前置条件 | 操作步骤 | 期望结果 |
|---|---|---|---|---|
| SKILL-001 | 历史预警 | 在线租户 | 发送“查看昨天离岗预警” | `QUERY_ALARMS` 调用告警查询 |
| SKILL-002 | 语义位置直播 | 门店有多个镜头 | 发送“给我看下门口的监控视频” | `VIEW_LIVE_STREAM`，自动匹配镜头并返回直播 |
| SKILL-003 | 直播执行 | 指定唯一镜头 | 发送“查看展厅 7 直播” | 创建临时会话，优先返回已验证可达的 HTTP-FLV 流 |
| SKILL-003A | HTTP-FLV 直播回退 | 同一会话 HLS 超时且 FLV 可达 | 查看展厅直播 | 使用 HTTP-FLV 播放，首帧后状态显示“播放中” |
| SKILL-003B | 直播失败状态 | 所有返回流均不可达 | 打开直播结果卡 | 显示“播放失败”和可理解提示，不误报“播放中” |
| SKILL-003C | 同源取流 | 已创建 FLV 会话 | 请求本地媒体代理路径 | 返回 `video/x-flv` 持续字节流，包含 FLV 头与 H.264 视频标签 |
| SKILL-003D | 媒体令牌校验 | 已创建 FLV 会话 | 使用错误令牌请求代理 | 返回 404，日志不记录原始令牌 |
| SKILL-004 | 录像缺时间 | 指定镜头 | 发送“查看展厅 7 录像” | 追问开始和结束时间 |
| SKILL-005 | 录像执行 | 镜头和时间完整 | 发送“查看昨天 10:00 到 10:10 展厅 7 录像” | 创建回放会话 |
| SKILL-006 | 当前快照 | 指定镜头 | 发送“获取展厅 7 当前画面” | 返回同步快照和拍摄时间 |
| SKILL-007 | 历史时刻抓图 | 指定历史时刻 | 发送“获取昨天 10:05 展厅 7 画面” | 不伪造图片，返回抽帧 Pipeline 与工具缺口 |
| SKILL-008 | 应用订阅 | 当前门店 | 发送“已经上线了哪些应用” | 返回真实已配置能力列表 |
| SKILL-009 | 设备状态 | 当前门店 | 发送“查看摄像头和服务器状态” | 摄像头真实汇总；服务器明确为 UNKNOWN |
| SKILL-010 | 画面与设备清单边界 | 当前门店 | 发送“看下店门口的摄像头画面” | 返回快照，不返回摄像头清单 |
