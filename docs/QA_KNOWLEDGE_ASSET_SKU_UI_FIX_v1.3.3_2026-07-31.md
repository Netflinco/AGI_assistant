# 知识库单图 SKU 界面修复自测报告

版本：v1.3.3  
日期：2026-07-31  
结论：通过，服务已重启。

## 缺陷与修复

原图片元数据区在窄卡片内横向排布 `SKU / 视角 / 特征说明`，最后两项超出可视范围，导致用户难以填写并保存。

- 已将每张已保留图片改为单列纵向素材行：首行缩略图、文件名和移除按钮；第二行完整显示三个字段。
- 每张图片的 `SKU` 为必填；`视角` 和 `特征说明` 为显式可选项。
- 前端原生校验与后端保存校验同时要求每张图片有 SKU，避免绕过页面写入无 SKU 图片。
- 图片地址导入支持“该图 SKU 或默认 SKU”二选一；视角和说明可留空。
- SKU 标签支持规范编码以及中文型号/色号组合（如 `松果棕`、`圣洁白+赤褐色`）；该规则同步到视觉结果白名单与图片标签链路。

## 验证

- 页面全量截图确认 5 张已保留图片逐行显示，字段未溢出。
- 浏览器检查：5 个 SKU 输入均带 `required`；全部视角和特征说明输入均不带 `required`。
- 自动化新增覆盖：缺少图片 SKU 被拒绝；仅填写 SKU、视角和说明留空可正常保存。
- 回归通过：`smoke_test.py`、`online_agent_test.py`、`credential_vault_test.py`。
