## 8000 服务重启与租户恢复

- 根因：OPPO 原为进程环境变量托管，旧进程停止后，新进程未继承凭证，浏览器仍携带 `X-Tenant-Code: oppo`，因此 bootstrap 返回 `TENANT_SCOPE_DENIED`。
- 修复：将 OPPO 凭证经在线验证后迁移至 Fernet 加密凭证库，不再依赖启动进程环境。
- 容错：前端遇到失效租户时，自动清理无效上下文，选择可用已接入租户并重试 bootstrap。
- 安全验证：数据库不含 AppSecret 明文，主密钥文件权限为 `0600`。
- 重启验收：首页、`oppo` bootstrap、`lianhe_tech` bootstrap 均返回 HTTP 200；页面可正常进入 `OPPO / 广州天河区天河城店`。

## 视觉分析服务配置持久化

- 根因：Qwen3-VL 地址、模型名和 API Key 仅存在旧进程环境变量中，重启后新进程无法恢复，因此抓图成功但分析返回 `VLM_NOT_CONFIGURED`。
- 修复：增加 `service_configs` 服务配置库，API Key 使用现有 Fernet 主密钥加密；模型名、接口地址和图片上限作为非敏感元数据保存。
- 加载：租户 Agent 构建时统一注入持久化配置，配置更新会使租户 Agent 缓存失效，防止继续使用旧实例。
- 审计：历史失败批次保留原始错误；仅新批次使用修复后的模型服务。

## 历史对话切换与断连容错

- 根因：本地 8000 服务停止时，历史对话详情接口请求失败；前端未统一捕获网络异常，导致浏览器原始 `Failed to fetch` 直接进入右下角提示。
- 修复：`api()` 统一将网络异常和非 JSON 响应转换为业务错误；历史对话切换遇到瞬时断连自动重试一次，持续失败时保留当前对话并显示中文提示。
- 体验：用户点击左侧历史记录时，只有详情加载成功才切换当前会话；失败时不清空消息区、不切乱租户门店上下文。
